# Sistema de Citas para Consultorio Clínico

Aplicación desarrollada en Java para simular un sistema de administración de citas de un consultorio clínico.

El sistema permite registrar doctores y pacientes, crear citas con fecha y hora, relacionar cada cita con un doctor y un paciente, controlar el acceso mediante credenciales de administrador y almacenar la información de forma persistente mediante archivos CSV.

## Instalación y configuración

### Requisitos

Para ejecutar y desarrollar el proyecto se requiere:

- Java Development Kit (JDK) 11.
- IntelliJ IDEA.
- Git.
- Sistema operativo compatible con Java.

El proyecto fue desarrollado y probado utilizando Java 11.
