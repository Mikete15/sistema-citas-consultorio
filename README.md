# Sistema de Citas para Consultorio Clínico

Programa desarrollado en Java para simular un sistema de administración de citas de un consultorio clínico.

## Instalación y configuración

Para ejecutar este proyecto se requiere:

- Java Development Kit (JDK) 11.
- IntelliJ IDEA.
- Git.
- Sistema operativo compatible con Java.

El proyecto debe descargarse o clonarse desde GitHub y abrirse utilizando IntelliJ IDEA con JDK 11 configurado.

## Uso del programa

El sistema permitirá:

- Registrar doctores.
- Registrar pacientes.
- Crear citas con fecha y hora.
- Relacionar cada cita con un doctor y un paciente.
- Controlar el acceso mediante usuarios administradores.
- Almacenar información mediante archivos.
